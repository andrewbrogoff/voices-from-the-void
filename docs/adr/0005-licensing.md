# Code is MPL-2.0, the API is MIT, and assets are CC-BY-4.0

Thaumcraft 6 and Witchery were abandoned under closed licences and could not be revived, while permissively licensed mods like Eidolon lived on through forks. So the mod ships open, and the licence is chosen by what a file does, not by its extension. **Code is MPL-2.0:** changes to our files stay open, but addons, modpacks and new files are untouched, and it stays GPL/LGPL-compatible because we don't attach Exhibit B. **The `api` source set is MIT,** so addon authors and compatible reimplementations can copy constants and interfaces without any copyleft question; the separate source set makes that boundary cheap. **Assets, data and docs are CC-BY-4.0,** so a fork keeps the art. We chose BY over BY-SA because it makes reuse simpler, not because SA conflicts with the code. Two things are carved out. The **branding** is reserved, with explicit permission for unmodified builds and truthful references, and forks must rebrand but keep `vftv`. The **owner's processed Voice recordings** get a narrower permission: the clips travel with the mod, its forks and modpacks, and appear in videos and streams, but may not be remixed, reused standalone or used to train voice models. The owner chose that. [`NOTICE.md`](../../NOTICE.md) holds the authoritative path-to-licence map. Every release links its corresponding source (MPL §3.2). Licences cover only the rights we actually hold, so AI provenance is recorded honestly instead of being papered over with a licence claim.
